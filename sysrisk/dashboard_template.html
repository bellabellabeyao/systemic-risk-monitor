    How a loss becomes systemic

    A systemic event needs four things at once: an excess that can unwind, channels for the loss to spread, too little liquidity to absorb the forced selling, and a shock that actually tests the system. Each link is scored 0–100 against its own history; the index is their average. The weakest link tells you where trouble would start.

    Narrative watch: risks the numbers cannot see yet

    Does the index work?

    A real-time test, as if the index had been run every month since 2010 using only data available then. That includes the choice of indicators: the evidence test that picks them is rerun each month on past data only, so the index is never graded on data it was built from. For each month we predict the bad-case (10th percentile) outcome over the next 12 months and compare the forecast error with simply using the historical 10th percentile. A positive score means the measure beats history; Giglio, Kelly & Pruitt (2016) run the same test on 19 published systemic risk measures.

    How this monitor works

    Why four links

    The literature splits systemic risk into the build-up of vulnerabilities and their amplification once a shock hits. The Build-up link covers the first. Contagion and shock absorbers are the amplifiers: one is about who is exposed to whom, the other about whether there is cash to absorb forced selling. Trigger is the shock itself. A high reading in one link alone is rarely a crisis; 2008 had all four.

    How scores work

    Every indicator is ranked against its own history (0 = calmest week on record, 100 = most dangerous), using only data available at the time. To feed the score, an indicator must pass two tests. First, published work must show it predicts crises, with no known structural break in our data. Second, each month it must pass an evidence test on our own data, using only what was known then: its past readings must have come before deeper drawdowns in US financial stocks over the next 12 months. Indicators that fail either test are shown as context. The data is real, but adding it would add noise. Each context row says why: failed test, too new to test, double counts, trends up, lags, global, or no evidence. Each link averages its scored indicators, and the index averages the four links. Bands come from the index's own crisis peaks (see the ruler above).
